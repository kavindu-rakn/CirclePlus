## v1 Definition of Done

v1 is complete when a user can:

1. sign in or enter demo mode;
2. browse a convincingly populated Stream;
3. create/edit a profile;
4. follow people and Collections;
5. create posts;
6. +1, comment, and reshare with correct authorization;
7. create/follow Collections;
8. join/post to Communities;
9. search people/Collections/Communities/public posts;
10. receive in-app notifications;
11. use audience sharing where historically relevant;
12. report/block abusive content/users;
13. use the application on desktop and mobile with historical visual fidelity.
