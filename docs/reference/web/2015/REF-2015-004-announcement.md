## What this reference proves

- Eddie Kessler’s announcement dates the start of the redesign to November 17, 2015 and places Communities/Collections at its center.
- Google states that web, Android and iOS were rebuilt and web required opt-in.

## What it does not prove

- Exact rollout completion, every platform’s simultaneous availability, CSS geometry or a specific app build.
- That November 18 in a secondary report is a verified original announcement date.
