# Historical Reference Pack

This directory is for source evidence, not generated design inspiration.

Suggested layout:

```text
reference/
  web/
    2015/
    2016/
    2017/
  android/
    2015/
    2016/
    2017/
  ios/
  interactions/
  tokens/
```

Do not commit copyrighted material unless repository licensing/usage permits it. Where necessary, keep external archive URLs plus measurement notes instead of redistributing files.

Each reference should have a companion metadata record using `reference-capture-template.md`.

## Current inventory

The [p0-04 source inventory](source-inventory.md) links all six supplied inputs and six additional source/candidate records, with date meanings, claim limits, citation tracing and explicit acquisition blockers. Year folders reflect verified source context; `undated/` keeps reports and artifacts whose historical date is unresolved. Existing originals stay in their original directories.

This is a bounded provenance pack. Target-era coverage, canonical approval and token measurements remain separate gated tasks.

The [p0-05 route/page/state matrix](route-page-matrix.md) maps all proposed routes and eight core groups across desktop web, mobile web, Android, iOS and tablet. It adds four bounded comparison/state records to the original twelve, preserves gaps and owners, and distinguishes visible stills from documented transitions. No canonical snapshot or token values are selected.
