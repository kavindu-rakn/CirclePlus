# Historical Reference Pack

Suggested layout:

```text
reference/
  web/
    2015/
    2016/
    2017/
  android/
    2015/
    2016/
    2017/
  ios/

```

Do not commit copyrighted material unless repository licensing/usage permits it. Where necessary, keep external archive URLs plus measurement notes instead of redistributing files.

Each reference should have a companion metadata record using `reference-capture-template.md`.
